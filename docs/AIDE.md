# Aide — Lexique forensique FR

**Cette aide est aussi disponible hors ligne dans une fenêtre LibreOffice** : menu **Lexique forensique > Aide…**. Elle est incluse directement dans le code de l'extension OXT et ne dépend pas de GitHub ou d'une connexion réseau. Les liens ci-dessous restent des ressources complémentaires en ligne.

## Rechercher un terme
Dans LibreOffice Writer, choisir **Lexique forensique > Rechercher un terme…**. Parcourir le lexique, consulter la définition et utiliser une formulation pour rapport si elle convient aux constatations.

## Créer ou modifier ses termes
La **Gestion des termes** permet de créer des fiches personnelles, avec leur définition, synonymes et plusieurs formulations pour rapport. Les données personnelles restent dans le profil local, indépendamment des mises à jour de l'extension.

## Exporter, importer et proposer
Dans le menu **Lexique forensique > Exporter / Importer…** :
- **Exporter** : sauvegarder la base personnelle complète au format JSON.
- **Importer et fusionner** : ajouter les éléments absents en conservant les données existantes.
- **Importer et remplacer** : remplacer les données personnelles après sauvegarde automatique.
- **Proposer des fiches personnelles** : sélectionner une ou plusieurs fiches dans la liste (Ctrl+clic ou Maj+clic selon le système), puis **Proposer les fiches sélectionnées**.

La proposition ouvre un formulaire GitHub prérempli. Elle **n'est pas envoyée automatiquement** ; le contributeur doit être connecté à GitHub et valider lui-même sa publication. Le contenu devient **public** : vérifier et retirer toute donnée personnelle, confidentielle ou issue d'une procédure. Si la sélection contient trop de texte pour le navigateur, proposer moins de fiches.

Les propositions ne modifient pas automatiquement la base officielle. Elles sont examinées puis éventuellement placées en attente de relecture et validées ultérieurement.

## Autres fonctions
- **Scénarios** : assembler plusieurs formulations du lexique pour faciliter la rédaction.
- **Vérifier le document** : identifier des expressions à franciser ou des termes déconseillés.
- **Mettre à jour…** : rechercher la dernière version de l'extension.
