# Système de fichiers

**Catégorie :** Technologie numérique

**Équivalent anglais :** File system

## Définition

Structure utilisée sur un volume physique ou virtuel pour organiser, stocker et retrouver des fichiers utilisateur et système. En criminalistique numérique, son interprétation est essentielle pour reconstituer l’organisation des données qu’il contient.

## Synonymes

- File system

## Exemple de formulation

L’analyse du système de fichiers permet d’identifier l’organisation des données présentes sur le support.
