# Fichier multimédia

**Catégorie :** Preuve numérique

**Équivalent anglais :** Media file

## Définition

Fichier contenant un contenu visuel ou sonore, notamment une photographie, une vidéo ou un enregistrement audio.

## Synonymes

- Média
- Fichier média

## Formulations pour rapport
