# Chiffrement

**Catégorie :** Cryptographie

**Équivalent anglais :** Encryption / Encrypted

## Définition

Procédé cryptographique transformant des données afin de les rendre inintelligibles sans la clé, le mot de passe ou le mécanisme cryptographique approprié.

## Synonymes

- Données chiffrées

## Termes déconseillés

- Cryptage

## Formulations pour rapport

### Support chiffré

Les données présentes sur le support sont protégées par chiffrement.

### Code de déchiffrement inconnu

Le code de déchiffrement du support n’est pas connu lors de notre examen.

### Accès aux données impossible

En l’absence du mécanisme de déchiffrement approprié, nos moyens techniques ne nous permettent pas d’accéder aux données protégées.
