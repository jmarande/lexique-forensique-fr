# Donnée supprimée

**Catégorie :** Preuve numérique

**Équivalent anglais :** Deleted data

## Définition

Donnée ayant fait l’objet d’une suppression logique ou applicative et dont tout ou partie du contenu, des métadonnées ou des traces peuvent éventuellement subsister dans les données examinées.

## Synonymes

- Élément supprimé
- Fichier supprimé

## Formulations pour rapport

### Donnée supprimée récupérée

Nous identifions une donnée supprimée dont le contenu demeure accessible dans les données extraites.

### Trace sans contenu

Nous identifions la trace d’un élément supprimé, sans que son contenu soit disponible dans les données extraites.

### Média supprimé

Un média supprimé est identifié ; son contenu n’est pas disponible dans les données extraites.
