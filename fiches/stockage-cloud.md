# Stockage dans le cloud

**Catégorie :** Technologie numérique

**Équivalent anglais :** Cloud storage

## Définition

Mode de stockage dans lequel les données sont hébergées sur des serveurs distants accessibles par réseau, généralement au moyen d'un compte utilisateur.

## Synonymes

- Stockage en nuage
- Stockage distant

## Exemple de formulation

Certaines données peuvent être conservées dans un espace de stockage distant et ne pas être présentes localement sur le support.
