# Code de déverrouillage

**Catégorie :** Procédure d’examen forensique

**Équivalent anglais :** Device passcode / Unlock code

## Définition

Code, mot de passe ou autre secret utilisé pour déverrouiller un équipement numérique et permettre l’accès à ses fonctions ou à ses données.

## Synonymes

- Code utilisateur
- Code de verrouillage
- Mot de passe de déverrouillage

## Formulations pour rapport

### Code inconnu

Le code de déverrouillage du support n’est pas connu lors de notre prise en charge.

### Aucun code identifié

Aucun code de déverrouillage n’a pu être identifié.

### Code communiqué

Le code de déverrouillage communiqué permet l’accès au support.
