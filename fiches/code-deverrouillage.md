# Code de déverrouillage

**Classification :** 🔬 Méthodologie forensique → Accès et authentification

**Statut :** En attente de relecture

**Équivalent anglais :** Device passcode / Unlock code

## Définition

Code numérique, alphanumérique, mot de passe ou autre secret utilisé pour déverrouiller un équipement numérique et permettre l'accès à ses fonctions ou à certaines de ses données. Son absence ou sa méconnaissance peut limiter les possibilités d'examen, sans nécessairement exclure toute acquisition de données.

## Synonymes

- Code utilisateur
- Code de verrouillage
- Mot de passe de déverrouillage

## Formulations pour rapport

### Code inconnu

Le code de déverrouillage du support n'est pas connu lors de notre prise en charge.

### Aucun code identifié

Aucun code de déverrouillage n'a pu être identifié.

### Code communiqué

Le code de déverrouillage communiqué permet l'accès au support.

### Code non communiqué

Aucun code de déverrouillage ne nous est communiqué dans le cadre de la mission.

### Tentative de déverrouillage infructueuse

Nous procédons à une tentative de déverrouillage au moyen du code disponible. Cette tentative ne permet pas d'accéder au support.

### Accès limité par le verrouillage

En l'absence de code de déverrouillage connu, les possibilités d'accès aux données du support sont limitées dans les conditions techniques rencontrées.
