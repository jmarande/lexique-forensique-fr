# Cache applicatif

**Classification :** 💻 Informatique → Systèmes d’exploitation et fichiers

**Statut :** En attente de relecture

**Équivalent anglais :** Application cache

## Définition

Ensemble de données conservées par une application afin d'accélérer son fonctionnement, de faciliter l'accès à certains contenus ou d'éviter leur téléchargement répété. Ces données peuvent notamment comprendre des images, des vidéos, des fichiers temporaires ou des informations résiduelles.

## Synonymes

- Cache d'application

## Formulations pour rapport

### Données de cache identifiées

L'examen des données met en évidence des éléments conservés dans le cache de l'application.

### Fichiers multimédias en cache

Nous identifions des fichiers multimédias présents dans les données de cache de l'application examinée.

### Attribution prudente

La présence d'un élément dans le cache applicatif ne permet pas, à elle seule, de déterminer les circonstances de son enregistrement ou d'établir qu'il a été volontairement consulté par l'utilisateur.

### Données résiduelles

L'examen des données de cache permet d'identifier des éléments résiduels dont la présence peut résulter du fonctionnement de l'application.
