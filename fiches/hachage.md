# Hachage

**Catégorie :** Méthode de criminalistique numérique

**Équivalent anglais :** Hash / Hashing

## Définition

Technique cryptographique permettant de calculer, à partir de données, une valeur de taille fixe utilisée notamment pour contrôler leur intégrité et comparer un original à une copie forensique.

## Synonymes

- Calcul d’empreinte
- Fonction de hachage

## Termes déconseillés

- Hashage

## Exemple de formulation

Une valeur de hachage est calculée afin de contrôler l’intégrité des données extraites.
